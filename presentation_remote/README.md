# 📱 OptiLoad Wireless Presentation Remote

Turn your **iPhone 7** (or any smartphone) into an ultra-low latency, zero-install presentation controller and trackpad for your **Lenovo IdeaPad Windows Laptop**.

---

## 🚀 Quick Start (In 10 Seconds)

1. **Connect both devices** (Laptop and iPhone 7) to the **same Wi-Fi** or laptop Mobile Hotspot.
2. **Double-click** `start_remote.bat` (or run `python server.py`).
3. Open your iPhone **Camera** or **Safari** and navigate to:
   ```
   http://192.168.1.10:8000
   ```
4. **Done!** Your phone instantly connects to your Windows laptop with sub-10ms response time.

---

## 🎯 Key Features

| Mode | What it does |
|---|---|
| **Slides Mode** | • Huge thumb-friendly **NEXT SLIDE** and **PREV SLIDE** buttons.<br>• **F5**: Start Slideshow from beginning.<br>• **Shift+F5**: Start from current slide.<br>• **Black Screen (B)**: Toggle blank screen during presentation Q&A.<br>• **Laser Pointer (Ctrl+L)**: Toggle PowerPoint built-in laser pointer.<br>• **Exit (Esc)**: End slideshow. |
| **Trackpad Mode** | • Glide thumb to glide Windows mouse cursor smoothly.<br>• Single tap to **Left Click**.<br>• Two-finger tap to **Right Click**.<br>• Two-finger drag to **Scroll** up/down.<br>• Physical Left & Right click buttons at the bottom. |
| **Air Mouse (Gyro Mode)** | • Hold the thumb trigger button and wave your iPhone in the air like a magic wand to move the cursor across the projection screen! |
| **Shortcuts & Media** | • Spacebar, Enter, Escape.<br>• Volume Up, Volume Down, Mute controls for presentation videos. |
| **Presenter Timer** | • Built-in 15-minute countdown clock with amber & red warnings and subtle haptic vibration so you never run over time. |
| **Screen Wake Lock** | • Automatically prevents your iPhone screen from dimming or going to sleep during your presentation. |
